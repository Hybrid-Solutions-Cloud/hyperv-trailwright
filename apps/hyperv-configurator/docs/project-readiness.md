# Configuration readiness

The review page computes draft or design-complete from required inputs, design errors and outstanding reviews. It does not depend on any bundled automation adapter or an execution environment.

Externally entered observations are displayed separately. Future dates, missing evidence, failed observations and inconsistent prerequisites remain visible. Observations do not alter design choices or certify deployment. JSON, Markdown, PDF and workbook reports share this assessment.

Readiness output schema 2 removes the consumer registry and adapter readiness. Saved project schema remains 30. Existing project files retain their answers and external implementation references.
